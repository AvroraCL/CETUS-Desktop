# CETUS 人工 UI 回归清单

在 `scripts/dev.ps1 smoke` 通过后，用 `scripts/dev.ps1 run -Profile ui-review -Port 0` 启动独立实例并逐项确认。

## 窗口与标题栏

- [ ] 从启动、DSH 加载完成到重连始终使用同一套窗口实现；圆角、边框或标题栏不会中途切换。
- [ ] 标题栏毛玻璃清晰可见，窗口保持直角，边缘不发糊，窗口阴影不叠入标题栏。
- [ ] 连续拖动窗口不少于 10 秒，无明显掉帧、停顿或拖动延迟。
- [ ] 最大化与还原各重复 5 次，布局、阴影、标题栏和拖动行为保持稳定。
- [ ] 最大化严格使用当前显示器工作区；任务栏位于左、上、右或下方时均不得被窗口覆盖。
- [ ] 最小化、最大化/还原、关闭按钮的常态、悬停和按下状态均清楚且一致。
- [ ] 最大化状态使用 Windows `ChromeRestore` 原生还原图标，无交叠线、方框或基线偏移。

## 显示与主题

- [ ] Windows 显示缩放 100% 时无裁切、错位或模糊边缘。
- [ ] Windows 显示缩放 150% 时无裁切、错位或模糊边缘。
- [ ] Windows 浅色主题下标题栏、按钮、文字和毛玻璃对比度正常。
- [ ] Windows 深色主题下标题栏、按钮、文字和毛玻璃对比度正常。

## 右侧栏

- [ ] Windows 标题栏顺序为最小化、最大化/还原、关闭；右侧栏按钮位于 DSH 主内容顶部栏右侧。
- [ ] DSH 顶部栏与页面原有背景、分隔线及深浅主题一致；侧栏按钮为 28px 圆形点击面和 16px 右面板图标。
- [ ] 右侧栏内容和拖拽条从 DSH 顶部栏下方开始，1px 分隔边线连续延伸到顶部并紧贴侧栏左缘，无断口、错位或间隙。
- [ ] 深色模式右侧栏背景为 `#1B1B1C`，浅色模式与 DSH 浅色侧栏协调。
- [ ] 启动只显示屏幕中央的静态品牌 splash（不抢焦点、无任务栏按钮），DSH 就绪后 splash 关闭、主窗口随之出现；启动期间托盘「显示窗口」可提前唤出主窗（splash 同时消失）。
- [ ] 首次启动侧栏默认收起；展开后无标签时显示「打开标签页」空态页与三张类型卡片，点击即创建对应标签。
- [ ] 展开和收起缓动方向分离：展开减速落位（约 240ms，点击即动、缓缓到位），收起加速离场（约 190ms，更快）；均为 slide-not-morph（滑动期间侧栏内容保持展开布局、被窗口右缘裁剪，不挤压回流），连续快速点击会从当前宽度反向，不闪跳、末端不弹跳、不卡住。
- [ ] 拖拽命中区无可见手柄或胶囊；悬停和拖动时仅显示系统调整光标，宽度限制在 300–1600px，并受当前窗口可用宽度约束。
- [ ] DSH 页面与侧栏零间隙直接相接，1px 分隔线由侧栏左描边绘制并紧贴面板；顶线与 DSH 顶栏线零间隙直连。
- [ ] 分隔线本身即拖拽把手：线两侧 8px 范围可拖拽改宽，悬停显示系统调整光标；上限随窗口宽度自适应（至少保留 480px 给 DSH 页面），恢复小窗口时自动收回超宽。
- [ ] 侧栏宽度在关闭、重启及托盘恢复后保持；每次启动侧栏默认收起；不同 Dev profile 互不影响。
- [ ] 窗口缩至 900px 时侧栏不会自动关闭，DSH 自带左侧栏仍可正常展开、收起和拖拽。
- [ ] 无标签时显示「打开标签页」空态页与三张类型卡片，点击即创建对应标签。
- [ ] 标签条支持多开：胶囊显示 Fluent 图标+标题（浏览器跟随页面标题）+关闭，圆角样式且宽度充裕；拖动标签可实时调整顺序，松开即落位；+ 新建按钮固定显示在最后一个标签之后。
- [ ] 侧栏图标统一来自 Fluent UI System Icons：空态卡片、类型菜单、标签胶囊、工具栏按钮均为矢量图标，深浅主题下颜色正确。
- [ ] ⌄ 下拉：搜索框过滤两组列表；「打开的标签页」可激活/关闭；「最近关闭的标签页」显示相对时间（刚刚/N分）并可恢复，浏览器恢复时还原地址。
- [ ] 浏览器支持网址、搜索、localhost、后退、前进、刷新；地址输入框为圆角样式，回车即导航（无独立「打开」按钮）；不得打开 `file://` 等本地特权地址。
- [ ] 「选择网页元素加入聊天」按钮：先打开网页，点击后悬停高亮页面元素，单击选中（Esc 取消）；元素摘要自动填入 DSH 聊天输入框，聊天未就绪时复制到剪贴板并有状态提示。
- [ ] 每个终端标签拥有独立的 ConPTY PowerShell 会话；优先启动 PowerShell 7（pwsh）并加载用户配置，显示版本横幅与自定义提示符（如 oh-my-posh），未安装时回退 Windows PowerShell；多标签互不串流，关闭标签或完全退出 CETUS 后无残留 PowerShell 子进程。
- [ ] 终端正确渲染 ANSI 颜色和光标控制，支持 ↑/↓ 命令历史、Tab 补全、Ctrl+C、粘贴及滚动历史。
- [ ] DSH 设置 → 通用设置下方出现「CETUS设置」分组（重开设置页不重复注入，切走再切回仍在）：启动时检查更新开关、检查更新按钮、关闭按钮行为开关、终端默认 Shell 三选、DSH 端口按钮，样式与 DSH 行一致，深浅主题正常。
- [ ] 设置页开关切换后 `%LocalAppData%\Cetus\settings.json` 实时更新；「关闭按钮行为」关掉后点窗口关闭按钮直接退出，开启则最小化到托盘；「检查更新…」按钮弹出更新检查结果。
- [ ] 「终端默认 Shell」切换到 cmd / PowerShell 后，新开终端标签使用对应 Shell（任务管理器查 Cetus 子进程命令行）；所选 Shell 缺失时自动回退。
- [ ] 「DSH 端口」行弹出端口设置对话框，保存后设置页按钮数值刷新。
- [ ] 侧栏分隔线手柄与 DSH 一致：透明骑线（分隔线两侧各 4px 可抓），动画期间可随时抓取拖拽打断，仅显示 col-resize 光标。
- [ ] 分隔线拖拽在浏览器/终端/状态标签激活时同样全高可抓（内容区左缘保留 12px 通道作为抓取区，浏览器页面自身仍贴住通道右缘；拖动改宽 300–1600px 全程可抓）。
- [ ] 浏览器标签打开网站后胶囊显示该站 favicon，加载失败回退地球图标。
- [ ] 「审查」标签：选择会话工作目录后列出 git 变更文件（状态徽标 M/A/D/U/R），点击文件显示彩色 diff；非 git 目录、无改动、无会话时给出对应提示。
- [ ] 调整侧栏和窗口尺寸后 xterm.js 与 ConPTY 行列数同步，提示符和全屏交互程序不截断、不重叠。
- [ ] `vim`、`more` 等交互式程序可正常输入、刷新和退出；PowerShell 初始提示符不因 WebView2 加载时序丢失。
- [ ] 文件页根目录自动跟随 DSH 当前选中会话的工作目录：切换会话后文件树跟随新根；无可用会话或 DSH 离线时保留上一个根并回退用户目录；无手动选目录按钮。
- [ ] 文件页预览：选中文本文件（含无扩展名的 LICENSE/Makefile 等）在左侧行内显示，超 4000 行/512KiB 截断有提示；图片（png/jpg/gif/webp/bmp/ico/svg）自动适配预览区大小等比显示；二进制文件显示说明；树列与预览列之间为可见 1px 边缘线，两侧 12px 均可拖拽调宽；文件名列过窄时可横向滚动查看全名；双击文件仍用系统程序打开。
- [ ] 状态标签：范围选择器（当前会话/当前项目/全部历史）切换正常，所有 KPI 与图表随范围变化。
- [ ] 状态标签洞察区：上下文占用 ≥70%/≥85% 分级提示（Critical 置顶带「新建会话」按钮）；缓存命中率好坏各有说明；running 会话输出速率超 2000 tokens/分时出现「中断会话」按钮；无异常显示「运行正常」。
- [ ] 状态标签 KPI：上下文占用条三色分级（绿/琥珀/红）、缓存命中率、消耗速度（空闲显示「空闲」）、LLM/工具耗时、任务进度（todos 完成/总数与当前项）。
- [ ] 状态标签图表：Token 用量堆叠比例条与图例、最近会话输出柱状图（悬停详情）；操作按钮（新建会话/中断会话）真实生效且结果有反馈。
- [ ] 状态标签排版：300px、默认 360px 和宽侧栏下卡片不溢出，三枚范围胶囊等宽；长洞察、长工作区路径、长模型名、长 todo 正常换行；深浅主题及 100%/150% DPI 下层级清晰。
- [ ] 状态标签布局刷新：上下文占用非零时拖动侧栏或缩放窗口，进度条实时贴合轨道；累计会话/轮次/步骤显示真实值；切换到其它标签超过 10 秒再返回，自动轮询继续工作。
- [ ] 状态标签余额：配置 DeepSeek Key 时显示平台余额与币种；未配置或第三方中转显示「未接入/不可用」；Key 不出现在任何界面文本中。DSH 离线时显示刷新失败而非崩溃。
- [ ] 自动更新回退：GitHub 不可达时自动切换 GitCode 源完成版本检查与下载；两源均失败时提示失败；可用源会被记住并在下次检查时优先尝试。

## 自动更新

- [ ] 托盘菜单在“设置 DSH 端口…”与分隔线之间有“检查更新…”入口。
- [ ] 已是最新版本时手动检查弹窗提示“当前已是最新版本”；断网时提示检查失败且应用不崩溃。
- [ ] 启动时的自动检查完全静默：失败或无更新无任何弹窗，不影响 DSH 启动流程。
- [ ] 启动静默检查发现新版本（安装版）时不再弹窗：托盘气泡提示“正在后台下载”，下载完成后自动运行安装器（/SILENT）并退出；安装完成后 CETUS 自动重新启动。
- [ ] 更新后的首次启动：右侧栏自动展开并在浏览器标签打开更新公告页（地址携带 `from`/`to` 参数），公告页高亮新版本卡片；`settings.json` 的 `LastLaunchVersion` 更新为新版本。
- [ ] 首次安装或版本未变化时启动：不自动打开公告页，不展开右侧栏。
- [ ] 便携版发现新版本：仅托盘气泡提示“无法自动安装”，点击气泡在应用内打开公告页。
- [ ] 手动“检查更新…”发现新版本时仍显示弹窗（新版本号、当前版本与更新说明）；安装版提供“立即更新”，便携版只提供“打开发布页”。
- [ ] “立即更新”展示下载进度条；点“取消”中止下载并恢复按钮，可再次发起。
- [ ] 自动更新下载重复校验：SHA256SUMS 缺失时不阻塞、不匹配时托盘气泡明确报错且应用不退出。
- [ ] 在 settings.json 中把 `CheckUpdatesOnStartup` 设为 `false` 后，启动不再发起检查。
- [ ] 更新公告页 https://avroracl.github.io/CETUS-Desktop/ 可访问：GitHub 源加载失败时自动回退 GitCode 源；两源均失败显示发布页链接；`?to=` 指定版本时对应卡片高亮并滚动到该卡片。

## 生命周期

- [ ] 关闭主窗口后正确进入托盘，DSH 继续可用。
- [ ] 从托盘恢复后窗口状态、毛玻璃和拖动性能不变。
- [ ] 托盘“退出”能完全关闭 CETUS，并回收其创建的 Node 子进程和监听端口。
- [ ] DSH 断开并自动重连后，窗口实现、标题栏和按钮样式不发生切换。

记录 Windows 版本、DPI、主题、profile、CETUS commit，以及任何失败项的日志路径 `.dev/profiles/ui-review/logs`。
