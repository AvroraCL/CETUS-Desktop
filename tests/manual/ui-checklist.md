# CETUS 人工 UI 回归清单

在 `scripts/dev.ps1 smoke` 通过后，用 `scripts/dev.ps1 run -Profile ui-review -Port 0` 启动独立实例并逐项确认。

## 窗口与标题栏

- [ ] 从启动、DSH 加载完成到重连始终使用同一套窗口实现；圆角、边框或标题栏不会中途切换。
- [ ] 标题栏毛玻璃清晰可见，窗口保持直角，边缘不发糊，窗口阴影不叠入标题栏。
- [ ] 连续拖动窗口不少于 10 秒，无明显掉帧、停顿或拖动延迟。
- [ ] 最大化与还原各重复 5 次，布局、阴影、标题栏和拖动行为保持稳定。
- [ ] 最大化严格使用当前显示器工作区；任务栏位于左、上、右或下方时均不得被窗口覆盖。
- [ ] 最小化、最大化/还原、关闭按钮的常态、悬停和按下状态均清楚且一致。
- [ ] 最大化状态使用 Windows `ChromeRestore` 原生还原图标，无交叠线、方框或基线偏移。

## 显示与主题

- [ ] Windows 显示缩放 100% 时无裁切、错位或模糊边缘。
- [ ] Windows 显示缩放 150% 时无裁切、错位或模糊边缘。
- [ ] Windows 浅色主题下标题栏、按钮、文字和毛玻璃对比度正常。
- [ ] Windows 深色主题下标题栏、按钮、文字和毛玻璃对比度正常。

## 右侧栏

- [ ] Windows 标题栏顺序为最小化、最大化/还原、关闭；右侧栏按钮位于 DSH 主内容顶部栏右侧。
- [ ] DSH 顶部栏与页面原有背景、分隔线及深浅主题一致；侧栏按钮为 28px 圆形点击面和 16px 右面板图标。
- [ ] 右侧栏内容和拖拽条从 DSH 顶部栏下方开始，1px 分隔边线连续延伸到顶部并紧贴侧栏左缘，无断口、错位或间隙。
- [ ] 深色模式右侧栏背景为 `#1B1B1C`，浅色模式与 DSH 浅色侧栏协调。
- [ ] 首次启动侧栏默认展开为 360px，默认显示浏览器页，左侧边界清楚。
- [ ] 展开和收起使用与 DSH 左侧栏一致的 300ms 缓动（slide-not-morph：滑动期间侧栏内容保持展开布局、被窗口右缘裁剪，不挤压回流），连续快速点击会从当前宽度反向，不闪跳或卡住。
- [ ] 拖拽命中区无可见手柄或胶囊；悬停和拖动时仅显示系统调整光标，宽度严格限制在 300–520px。
- [ ] 8px 拖拽命中区覆盖在 WebView/右栏边界两侧，边线与内容边界完全贴合且不产生空白缝。
- [ ] 侧栏开关和宽度在关闭、重启及托盘恢复后保持；不同 Dev profile 互不影响。
- [ ] 窗口缩至 900px 时侧栏不会自动关闭，DSH 自带左侧栏仍可正常展开、收起和拖拽。
- [ ] 浏览器支持网址、搜索、localhost、后退、前进、刷新；不得打开 `file://` 等本地特权地址。
- [ ] 终端首次切换时才启动 PowerShell，连续命令共享会话，CETUS 完全退出后无残留 PowerShell 子进程。
- [ ] 文件页默认显示用户目录，目录按需展开，选择新根目录、刷新和双击打开文件均正常。

## 自动更新

- [ ] 托盘菜单在“设置 DSH 端口…”与分隔线之间有“检查更新…”入口。
- [ ] 已是最新版本时手动检查弹窗提示“当前已是最新版本”；断网时提示检查失败且应用不崩溃。
- [ ] 启动时的自动检查完全静默：失败或无更新无任何弹窗，不影响 DSH 启动流程。
- [ ] 有新版本时弹窗显示新版本号、当前版本与更新说明；安装版提供“立即更新”，便携版只提供“打开发布页”。
- [ ] “立即更新”展示下载进度条；点“取消”中止下载并恢复按钮，可再次发起。
- [ ] 下载完成后自动运行安装器（/SILENT），CETUS 随后退出；重复校验：SHA256SUMS 缺失时不阻塞、不匹配时明确报错。
- [ ] 在 settings.json 中把 `CheckUpdatesOnStartup` 设为 `false` 后，启动不再发起检查。

## 生命周期

- [ ] 关闭主窗口后正确进入托盘，DSH 继续可用。
- [ ] 从托盘恢复后窗口状态、毛玻璃和拖动性能不变。
- [ ] 托盘“退出”能完全关闭 CETUS，并回收其创建的 Node 子进程和监听端口。
- [ ] DSH 断开并自动重连后，窗口实现、标题栏和按钮样式不发生切换。

记录 Windows 版本、DPI、主题、profile、CETUS commit，以及任何失败项的日志路径 `.dev/profiles/ui-review/logs`。
