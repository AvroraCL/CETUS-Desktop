# CETUS 人工 UI 回归清单

在 `scripts/dev.ps1 smoke` 通过后，用 `scripts/dev.ps1 run -Profile ui-review -Port 0` 启动独立实例并逐项确认。

## 窗口与标题栏

- [ ] 从启动、DSH 加载完成到重连始终使用同一套窗口实现；圆角、边框或标题栏不会中途切换。
- [ ] 标题栏毛玻璃清晰可见，窗口保持直角，边缘不发糊，窗口阴影不叠入标题栏。
- [ ] 连续拖动窗口不少于 10 秒，无明显掉帧、停顿或拖动延迟。
- [ ] 最大化与还原各重复 5 次，布局、阴影、标题栏和拖动行为保持稳定。
- [ ] 最大化严格使用当前显示器工作区；任务栏位于左、上、右或下方时均不得被窗口覆盖。
- [ ] 最小化、最大化/还原、关闭按钮的常态、悬停和按下状态均清楚且一致。
- [ ] 最大化状态使用 Windows `ChromeRestore` 原生还原图标，无交叠线、方框或基线偏移。

## 显示与主题

- [ ] Windows 显示缩放 100% 时无裁切、错位或模糊边缘。
- [ ] Windows 显示缩放 150% 时无裁切、错位或模糊边缘。
- [ ] Windows 浅色主题下标题栏、按钮、文字和毛玻璃对比度正常。
- [ ] Windows 深色主题下标题栏、按钮、文字和毛玻璃对比度正常。

## 设置集成

- [ ] DSH 设置 → 通用设置下方出现「CETUS设置」分组（重开设置页不重复注入，切走再切回仍在）：启动时检查更新开关、检查更新按钮、关闭按钮行为开关、DSH 端口按钮，样式与 DSH 行一致，深浅主题正常。
- [ ] 设置页开关切换后 `%LocalAppData%\Cetus\settings.json` 实时更新；「关闭按钮行为」关掉后点窗口关闭按钮直接退出，开启则最小化到托盘；「检查更新…」按钮弹出更新检查结果。
- [ ] 「DSH 端口」行弹出端口设置对话框，保存后设置页按钮数值刷新。

## 桌面集成

- [ ] 设置页「CETUS设置」出现三个新开关：任务完成提醒、全局快捷键、开机自启，样式与 DSH 行一致，重开设置页不重复注入，深浅主题正常。
- [ ] 会话任务完成且 CETUS 不是前台窗口时，托盘弹出「任务完成」气泡（标题含会话名）；点击气泡唤起主窗口。
- [ ] CETUS 正在前台时任务完成不弹通知；同一会话连续完成不会在冷却期内重复轰炸。
- [ ] 关闭「任务完成提醒」后不再弹出气泡；设置实时持久化到 `%LocalAppData%\Cetus\settings.json`。
- [ ] Ctrl+Alt+Space：CETUS 在前台时按下隐藏到托盘，托盘/后台状态按下唤起并前置；「全局快捷键」关闭后热键失效，重新开启即恢复。
- [ ] 其他程序占用 Ctrl+Alt+Space 时 CETUS 启动不受影响（静默降级），设置开关保持开启但热键不生效，退出 CETUS 后不残留全局热键。
- [ ] 开启「开机自启」后 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 出现 `Cetus` 值，内容为带引号的 exe 路径加 `--background`。
- [ ] `Cetus.exe --background` 启动：无 splash、无主窗口，仅托盘图标；DSH 在后台就绪，托盘「显示窗口」或热键可唤出；启动失败时仍弹出错误提示。
- [ ] 关闭「开机自启」后注册表值被删除；手动删除注册表值后设置页开关如实显示为关；exe 被移动后旧自启条目不会误判为开启。
- [ ] 「任务完成」气泡点击后窗口前置且 DSH 页面自动聚焦刚完成的那个会话（而非仅打开首页）。
- [ ] 窗口位置与尺寸跨重启保持（含多显示器负坐标）；最大化状态重启后仍最大化，且还原后的边界正确；最小化状态下退出不覆盖已保存的位置。
- [ ] 更新后台下载时任务栏图标显示进度（先不确定后确定百分比）；下载完成/失败/取消后进度清除；手动「立即更新」的进度条与任务栏同步。

## 工作区直达

- [ ] 托盘菜单出现「最近工作区」子菜单与「打开工作区…」入口；「打开工作区…」弹出目录选择器，选中后主窗口前置并自动打开该目录的新会话。
- [ ] `Cetus.exe <目录>` 直接启动：DSH 就绪后页面自动聚焦该目录的会话；启动期间传入目录也能在就绪后打开，不丢请求。
- [ ] 已有实例运行时再次 `Cetus.exe <目录>`：第二个进程静默退出，请求转发给现有窗口并打开会话；无参数二次启动仅唤起窗口，不再弹「已在运行」提示框。
- [ ] 连续快速打开多个不同目录：不产生交错报错，最终停在最后请求的会话。
- [ ] 目录不存在或传入文件路径时弹托盘气泡报错，应用不崩溃。
- [ ] 最近工作区最多保留 10 条，同目录去重并置顶；`%LocalAppData%\Cetus\recent-workspaces.json` 与菜单、Jump List 一致。
- [ ] 任务栏图标右键 Jump List 显示最近工作区（目录名+完整路径描述），点击后经现有实例打开对应会话。
- [ ] `HKCU\Software\Classes\cetus` 注册表包含默认值「URL:CETUS 工作区」、空串 `URL Protocol` 值和 `shell\open\command`（指向当前 exe）；在浏览器输入 `cetus://open?path=<目录>` 能唤起 CETUS 打开该目录。
- [ ] DEV 模式启动不写协议注册表；便携版与安装版行为一致。
- [ ] 完全退出后再次启动，最近工作区列表保持；卸载后 `recent-workspaces.json` 被清理。

## 自动更新

- [ ] 托盘菜单在“设置 DSH 端口…”与分隔线之间有“检查更新…”入口。
- [ ] 已是最新版本时手动检查弹窗提示“当前已是最新版本”；断网时提示检查失败且应用不崩溃。
- [ ] 启动时的自动检查完全静默：失败或无更新无任何弹窗，不影响 DSH 启动流程。
- [ ] 启动静默检查发现新版本（安装版）时不再弹窗：托盘气泡提示“正在后台下载”，下载完成后自动运行安装器（/SILENT）并退出；安装完成后 CETUS 自动重新启动。
- [ ] 更新后的首次启动：在默认浏览器打开更新公告页（地址携带 `from`/`to` 参数），公告页高亮新版本卡片；`settings.json` 的 `LastLaunchVersion` 更新为新版本。
- [ ] 首次安装或版本未变化时启动：不自动打开公告页。
- [ ] 便携版发现新版本：仅托盘气泡提示“无法自动安装”，点击气泡在浏览器打开公告页。
- [ ] 手动“检查更新…”发现新版本时仍显示弹窗（新版本号、当前版本与更新说明）；安装版提供“立即更新”，便携版只提供“打开发布页”。
- [ ] “立即更新”展示下载进度条；点“取消”中止下载并恢复按钮，可再次发起。
- [ ] 自动更新下载重复校验：SHA256SUMS 缺失时不阻塞、不匹配时托盘气泡明确报错且应用不退出。
- [ ] 在 settings.json 中把 `CheckUpdatesOnStartup` 设为 `false` 后，启动不再发起检查。
- [ ] 更新公告页 https://avroracl.github.io/CETUS-Desktop/ 可访问：GitHub 源加载失败时自动回退 GitCode 源；两源均失败显示发布页链接；`?to=` 指定版本时对应卡片高亮并滚动到该卡片。

## 生命周期

- [ ] 关闭主窗口后正确进入托盘，DSH 继续可用。
- [ ] 从托盘恢复后窗口状态、毛玻璃和拖动性能不变。
- [ ] 托盘“退出”能完全关闭 CETUS，并回收其创建的 Node 子进程和监听端口。
- [ ] DSH 断开并自动重连后，窗口实现、标题栏和按钮样式不发生切换。

## 端口自愈

- [ ] 用其他程序占住配置端口（如 3080）后启动 CETUS：不再弹启动失败，托盘弹出「端口已切换」气泡（说明旧端口与新端口），DSH 在空闲端口上正常就绪。
- [ ] 点击「端口已切换」气泡可唤起主窗口；DSH 设置页「CETUS设置 → DSH 端口」显示新端口。
- [ ] 切换后的端口已持久化到 `%LocalAppData%\Cetus\settings.json`，重启与托盘恢复后继续使用新端口。
- [ ] 端口被一个健康 DSH 服务占用时仍按原逻辑复用，不触发切换；宽限期内释放的端口（上次 CETUS 退出中）也正常复用。
- [ ] settings.json 设置 `CETUS_PORT` 环境变量覆盖时不自愈：端口被占仍报启动失败，settings.json 不被改写。
